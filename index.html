원페이지 포스터

상세한 내용을 담기보다, 그래픽에 집중한 원페이지 포스터입니다.
데뷔나 생일, 역팬데이, 오리지널 아바타 공개 등 중요한 이벤트 라이브를 위해 제작됩니다.

02 · Lookbook Package

룩북 패키지

룰렛 보상이나 API 보상 안내를 목적으로 만들어지는 시리즈 이미지입니다.
여러가지 의상과 헤어, 확정 구매 또는 API 달성 공약을 포함한 상세 페이지가 필요할 때 룩북 패키지를 추천합니다.

위 4장 구성이 기본이며, 변경 시 사전 협의가 필요합니다.
페이지 추가 시 장당 추가금이 발생합니다. (이때 베이스 디자인은 다른 페이지와 동일합니다.)
사전 협의 시, '렌즈 선택'을 넣어 달라고 말씀해 주시면 추가금 없이 상대적으로 구성이 적은 페이지에 함께 넣어 드릴 수도 있습니다.
